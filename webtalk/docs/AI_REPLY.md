# 내 말투로 답장 추천

말투 선택 6개, 상황별 답변 6개, 문장 고쳐 쓰기 3개로 구성된 설문을 참고해 LLM이 답장 초안을 추천합니다.
모델 파인튜닝이나 자동 전송 기능이 아닙니다.

## 사용 방법

1. 채팅 화면 오른쪽 위 **내 말투 설정**을 엽니다.
2. 친구·어른·선배/동료·후배·처음 만난 사람 중 질문지 관계를 고르고, 말투 선택 6개(높임말, 길이, 띄어쓰기, 긍정 표현, 웃음, 이모지)를 설정합니다.
3. 상황 질문 6개에 평소처럼 답하고, 문장 3개를 내 말투로 고칩니다. 예: `오늘 저녁에 뭐 먹을래?` → `저녁에 뭐 먹을 거?`.
4. 원하면 피하고 싶은 표현을 쉼표로 구분해 적고 저장합니다. 기존 5개 답변은 유지되며 추가 항목만 채우면 됩니다.
5. 대화 화면의 **상대방과의 관계**를 고른 뒤 **상대방이 보낸 말풍선을 클릭**하면 그 메시지에 대한 답장을 추천합니다. 키보드로 말풍선에 초점을 맞춘 후 Enter/Space를 눌러도 됩니다.
6. 후보를 선택하면 입력창에 초안이 들어갑니다. 검토·수정 후 직접 전송합니다.

선택한 메시지는 입력창 위에 표시되며 해제할 수 있습니다. 클릭 시 작성 중인 입력은 유지하고,
후보를 선택했을 때만 입력창 내용을 바꿉니다. 선택 상태에서 추천 버튼을 누르면 입력 문장도 답장의 의도로 참고합니다.
여기서 메시지 선택은 AI 추천 대상 지정이며, 전송 메시지에 인용 연결을 추가하는 기능은 아닙니다.

선택한 메시지가 없으면 입력 문장의 뜻을 유지하며 말투를 다듬고, 입력창도 비어 있으면 최근 대화로 답장을 추천합니다.
추천 결과는 최대 3개입니다. 생성 중 입력·선택·방이 바뀌면 이전 결과를 버립니다.
생성 중 다른 메시지를 선택하면 진행 중인 요청이 끝난 뒤 마지막 선택에 대해 추천합니다.
질문지 수정과 삭제는 **내 말투 설정**에서 가능합니다.
한 계정에서 관계마다 별도의 말투 프로필을 저장합니다. 수정·삭제는 선택한 관계에 적용되며 다른 관계의 답변은 유지합니다.

## 로컬 모델 실행

기본 연결은 Ollama의 `gemma3:12b`입니다. 모델 파일 다운로드에는 약 8.1GB가 필요합니다.
macOS에서 Homebrew를 사용한다면:

```bash
brew install ollama
ollama serve
```

Ollama를 실행한 상태에서 다른 터미널에서:

```bash
ollama pull gemma3:12b
./mvnw spring-boot:run
```

이미 Ollama 서버가 실행 중이면 `ollama serve`를 다시 실행할 필요는 없습니다.
모델 실행 속도와 추천 품질은 기기와 모델에 따라 달라집니다. 한 요청의 제한 시간은 60초입니다.
연결 실패·시간 초과·잘못된 모델 응답은 화면에 오류로 표시하며 고정 문장을 AI 결과처럼 대신 보여주지 않습니다.

다른 설치된 Ollama 모델은 환경 변수로 선택할 수 있습니다.

```bash
export WEBTALK_AI_MODEL='설치한-모델명'
export WEBTALK_AI_URL='http://localhost:11434'
./mvnw spring-boot:run
```

[Ollama API 문서](https://docs.ollama.com/api/chat) · [기본 모델 설명과 라이선스](https://ollama.com/library/gemma3:12b)

## 데이터와 처리 범위

- `reply_style_relationship_profiles` 테이블에 사용자·관계별 질문지를 저장합니다. `reply_style_profiles`는 이전 단일 질문지 및 관계 미지정 요청과의 호환을 유지합니다.
- 요청한 사용자 본인이 선택한 관계의 질문지, 선택한 방의 대화 본문과 발신 구분, 현재 입력 문장을 AI에 전달합니다. 메시지를 선택했으면 해당 메시지까지 최대 10개를 사용하고 이후 메시지는 제외합니다. 선택하지 않았으면 최근 10개를 사용합니다.
- 모델에는 로그인 아이디·비밀번호·세션 쿠키를 전달하지 않습니다.
- 기본 로컬 모델은 이 데이터를 외부 AI API에 전송하지 않습니다. 서버 운영자가 URL을 외부 서버로 바꾸면 해당 서버로 전달됩니다.
- 방 구성원 검사 후 선택한 메시지가 해당 방의 상대방 메시지인지 검증합니다. 추천 결과는 요청한 사용자에게만 반환합니다.
- 선택 메시지의 답장 내용을 먼저 생성하고, 별도 호출로 설문을 참고해 말투를 다듬습니다. 내용 생성 단계에는 설문 속 상황 예시를 전달하지 않습니다.
- 추천만으로 메시지를 DB에 저장하거나 WebSocket으로 전송하지 않습니다.
- 질문지의 상황을 현재 사실로 가정하지 않도록 지시하지만, 생성 결과의 정확성이 보장되지는 않습니다. 전송 전 확인하세요.
- 개인정보 삭제는 말투 설정 삭제 기능으로 처리합니다. 기존에 전송한 대화 메시지는 별도로 남습니다.

## 관련 코드와 API

- `ai/StyleProfile.java`: 질문지와 입력 검증
- `ai/ReplySuggestionService.java`: 사용자별 저장·삭제, 방 권한 확인, 프롬프트 데이터 구성
- `ai/OllamaReplyModel.java`: 로컬 모델 호출, 응답 형식·길이 검사
- `ai/ReplySuggestionController.java`: 인증된 사용자 대상 API
- `static/js/reply-assist.js`: 질문지 편집과 추천 후보 선택, 오래된 결과 무시

| 메서드 | 경로 | 기능 |
| --- | --- | --- |
| GET | `/api/me/reply-style` | 선택적 `?relationship=관계`로 관계별 질문·프로필 조회 |
| POST | `/api/me/reply-style` | `relationship`, `answers` 6개, `preferences` 6개, `rewrites` 3개, 선택적 `avoidedExpressions` 저장 |
| DELETE | `/api/me/reply-style` | `?relationship=관계`로 해당 관계 삭제 (미지정 시 전체 삭제) |
| POST | `/api/chat-rooms/{roomId}/reply-suggestions` | `draft`와 선택적 `replyToMessageId`, `relationship`을 받아 답장 후보 반환 |

## 검증

`./mvnw test`로 기본 컨텍스트 로딩, HTTP API 인증·계정 격리·입력 검증·방 권한·삭제·추천 시 메시지 미저장,
모델 장애 응답 및 Ollama 응답 파싱을 확인합니다. 자동 테스트는 모델 대역을 사용하며 실제 추천 품질 평가는 별도로 필요합니다.


## 실제 모델 및 화면 검증

실제 모델 품질 평가는 별도로 실행합니다(로컬 Ollama와 모델 필요).

```bash
WEBTALK_RUN_LLM_EVAL=true ./mvnw -Dtest=ReplyStyleEvaluationTests test
```

2026-10-04 Chrome에서 기존 답변 유지, 설문 15항목 저장·재조회, 상대 메시지 클릭·키보드 선택,
연속 선택 시 마지막 요청 처리, 방 변경 후 이전 결과 무시, 후보 선택 후 직접 전송하는 흐름과 모바일 화면을 확인했습니다.
실제 Gemma 3 12B는 `저녁 뭐 먹을래?`에 `뭐 먹을 거?`, `아직 생각 안 나네.`를 추천했습니다.

기본 자동 테스트 4개와 실제 모델 평가 3개(질문 어미·존댓말·축약형 축하 표현)가 통과했습니다.

말투 선택과 예시는 생성 지침이며 모든 표현이 항상 동일하게 재현되지는 않습니다.
말투 기준을 만족하는 후보가 없으면 안내를 표시하며 고정 문장을 모델 결과로 대신 보여주지 않습니다.
여러 생성 단계의 제한 시간은 합계 60초입니다.
