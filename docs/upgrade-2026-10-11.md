# 2026-10-11 WebTalk 업그레이드

## 변경된 기능

- 상대방이 보낸 안 읽은 메시지만 대화 목록 숫자에 포함합니다. 내가 보낸 메시지는 제외합니다.
- 방을 열어 메시지를 표시하면 읽음 처리하며, 읽음 ID는 과거로 돌아가지 않습니다. 방 구성원과 메시지의 소속 방을 검증합니다.
- 다른 방의 숫자·미리보기는 화면이 열린 동안 약 3초마다 갱신합니다. 재연결과 탭 복귀 시 최근 대화를 다시 불러옵니다.
- 친구·어른·선배/동료·후배·처음 만난 사람별로 질문 6개, 말투 선택 6개, 고쳐 쓰기 3개를 저장합니다. 기존 단일 질문지도 해당 관계에 보존합니다.
- 대화 화면에서 선택한 관계의 질문지로 AI 답장을 추천합니다. 관계 선택은 현재 브라우저에서 계정·방별로 보관합니다.
- WebSocket의 localhost 제한을 동일 출처 검사로 바꾸고, 서버 바인딩과 HTTPS 프록시 전달 헤더를 설정했습니다. H2 콘솔은 기본으로 비활성화했습니다.
- 별도 서버가 없을 때 임시 공용 주소를 만들 수 있도록 `webtalk/scripts/share.sh`를 추가했습니다.

## 검증

`cd webtalk && ./mvnw test`로 기본 테스트 7개가 통과했습니다. 실제 Ollama 품질 평가 3개는 기본 실행에서 제외됩니다.

추가 테스트는 상대 메시지 집계, 읽음 후 숫자 제거, 새 메시지 증가, 권한 검사, 읽음 ID 역행 방지,
관계별 질문지·기존 답변 보존·계정 격리·선택한 질문지의 추천 적용, HTTPS 공용 주소를 가정한 WebSocket 연결과 다른 출처 차단을 확인합니다.

서로 다른 실제 네트워크에서의 시연과 공용 URL 생성·상시 운영 서버 배포는 아직 수행하지 않았습니다.
실행 방법은 [외부 접속 안내](../webtalk/docs/REMOTE_ACCESS.md)와 [AI 답장 추천 안내](../webtalk/docs/AI_REPLY.md)를 참고하세요.
