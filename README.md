# Creative-Engineering

Creative Engineering 수업에서 진행하는 개인 프로젝트 **WebTalk**의 소스 코드와 주차별 진행 기록입니다.

## 프로젝트 소개

WebTalk는 별도 앱 설치 없이 브라우저에서 사용할 수 있는 1대1 실시간 메신저 프로토타입입니다.
회원가입과 로그인 후 상대방을 검색해 채팅방을 만들고 메시지를 주고받으며, 대화 기록을 저장합니다.

## 만들고 싶은 이유

웹 화면과 서버, 데이터베이스를 연결하는 과정을 직접 구현하고 실시간 통신의 동작 방식을 익히기 위해 선정했습니다.
GitHub에 구현 내용과 진행 과정을 함께 기록합니다.

## 예상 사용자

브라우저에서 간단한 1대1 텍스트 대화를 나누려는 사용자입니다.
로컬 실행과 공용 서버·터널 주소를 통한 접속을 지원하는 수업용 프로토타입입니다. 서로 다른 네트워크에서도 같은 서버 주소로 접속하여 대화할 수 있습니다.

## 실행 방법

JDK 17 이상을 준비하고 저장소 루트에서 실행합니다.

```bash
cd webtalk
./mvnw spring-boot:run
```

Windows PowerShell에서는 `./mvnw.cmd spring-boot:run`을 실행합니다.
브라우저에서 <http://localhost:8080>에 접속합니다. 일반 창과 시크릿 창에서 각각 다른 계정으로 로그인하면 됩니다.
첫 실행 시 의존성 다운로드가 필요하며, 채팅 화면의 STOMP.js는 CDN에서 불러옵니다.

## 현재 진행 상태

읽음 처리, 관계별 말투 질문지와 답장 추천, 외부 접속 설정까지 구현했습니다.
기본 자동 테스트는 7개 통과했으며 실제 Ollama 품질 평가 3개는 별도 실행 항목으로 기본 실행에서는 건너뜁니다.
외부 접속용 공용 주소 생성과 상시 서버 배포는 별도 작업이며, 실제 서로 다른 네트워크 간 시연은 아직 완료하지 않았습니다.

## 주차별 기록

### 1주차

* 이번 주에 한 일: GitHub 저장소를 만들고 README를 작성했습니다.
* 새롭게 알게 된 것: GitHub 저장소를 만드는 방법과 Markdown 문법을 알게 되었습니다.
* 어려웠던 점: 아직 프로젝트 주제를 정하지 못해 어떤 내용을 만들지 결정하는 것이 어려웠습니다.
* 다음 주에 할 일: 프로젝트 아이디어를 찾아보고 주제를 정할 예정입니다.

### 2~3주차

- 진행한 일: 프로젝트를 WebTalk로 선정하고 회원가입부터 실시간 1대1 채팅까지 프로토타입을 구현했습니다.
- 구현 방식: Spring Security 세션 인증, REST API, WebSocket/STOMP, H2 저장소를 연결하고 HTML/CSS/JavaScript로 화면을 구성했습니다.
- 기술 정리: REST 요청과 WebSocket 연결의 인증 공유, 방 구성원 검사, DB 저장 후 메시지 발행, 요청 ID를 통한 전송 상태 연결을 정리했습니다.
- 남은 과제: 읽음 처리, 재연결 시 누락 메시지 처리, 동시 요청 처리와 기능 테스트 보강이 필요합니다.
- 다음 작업: 두 계정으로 브라우저 시연을 확인하고 실행 화면 및 테스트 결과를 기록할 예정입니다.
