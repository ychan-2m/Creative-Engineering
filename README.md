# Creative-Engineering
Creative Engineering 수업 프로젝트 관리 및 일정 관리


## 프로젝트 소개

이번 학기 동안 진행할 개인 프로젝트입니다.

아직 구체적인 프로젝트 주제는 정하지 않았으며, 관심 있는 분야와 구현 가능한 내용을 찾아보면서 프로젝트를 선정할 계획입니다.

## 만들고 싶은 이유

수업에서 배운 내용을 활용하여 직접 프로젝트를 기획하고 구현해 보고 싶습니다.

또한 GitHub를 사용하여 프로젝트의 진행 과정과 새롭게 배운 내용을 꾸준히 기록하고 싶습니다.

## 예상 사용자

현재 프로젝트 주제를 정하지 않아 예상 사용자는 계획 중입니다.

프로젝트 주제를 선정한 후 구체적으로 작성할 예정입니다.

## 현재 진행 상태

현재 GitHub 저장소를 생성하고 README를 작성한 상태입니다.

프로젝트 주제는 아직 선정하지 않았으며, 앞으로 관심 있는 분야를 조사하여 주제를 결정할 예정입니다.
